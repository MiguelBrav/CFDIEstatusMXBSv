# CFDI Estatus MX

Aplicación web en **Blazor Server** para consultar el **estatus de un CFDI** y determinar si puede ser cancelado, simulando el comportamiento del servicio del SAT.

> Proyecto personal y demostrativo. No afiliado al SAT.

## Función
Consulta si un CFDI está **Vigente o Cancelado**, si es **Cancelable** y el **estatus de la cancelación**.

## Nota
Usa un servicio mock con datos de ejemplo.  
No se almacenan datos fiscales reales.

Autor: Miguel Segura

# CFDI Status MX

Blazor Server web app to check the **status of a CFDI** and determine if it can be canceled, simulating the official SAT service behavior.

> Personal demo project. Not affiliated with SAT.

## Purpose
Check CFDI status (**Active / Canceled**), cancelability, and cancellation state.

## Note
Uses mock data for demonstration only.  
No real fiscal data is stored.

Author: Miguel Segura
